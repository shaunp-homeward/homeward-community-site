# Apply Homeward V7.1

Upload the **contents of this folder** over the repository `staging` branch, preserving paths. Do not upload the enclosing folder as a new directory.

Netlify will run `npm run build` and publish `dist/`.

Before promoting staging, run or confirm:

```bash
npm run build
npm run verify
```

Then test the Resources footer link and submit one clearly labeled staging test through each form.
