# Which Homeward repository to use

| Repository | Purpose | Use for website changes? |
| --- | --- | --- |
| [homeward-community-site](https://github.com/shaunp-homeward/homeward-community-site) | Public Homeward website, content, images and CMS | **Yes** |
| [homeward-command-center](https://github.com/shaunp-homeward/homeward-command-center) | Private Airtable CRM app for tasks, contacts and programs | No; keep for CRM work |
| [shaun-ai-command-center](https://github.com/shaunp-homeward/shaun-ai-command-center) | Marty and other role instructions, shared context and work records | Read the relevant instructions; website code belongs above |

These are three different applications/resources. No redundant website repository
was found among them. No repository was deleted, archived or removed from the
environment. Use `homeward-community-site` when selecting a repository for website work.
