# Read Me First — Homeward Website V7.1

This package contains the canonical V7.1 source and a current root-level static preview.

- Open `index.html` to review V7.1 immediately.
- Edit canonical CMS content in `content/`.
- Run `npm run build` after edits.
- Run `npm run verify` before deployment.
- Netlify deploys `dist/`.
- The build also refreshes the root preview to prevent stale HTML.

The root `index.html` and `dist/index.html` should always show the same V7.1 homepage.
