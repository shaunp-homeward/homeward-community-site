# Upload Homeward V6.2.1 to staging

1. Extract `Homeward_Website_V6_2_1_Update_Only.zip`.
2. In GitHub, select the `staging` branch.
3. Choose **Add file → Upload files**.
4. Upload everything inside the extracted folder.
5. Commit directly to `staging` with: `Fix Remembering desktop layout — V6.2.1`.
6. Wait for Netlify to deploy, then hard-refresh the staging page with `Ctrl + Shift + R`.
