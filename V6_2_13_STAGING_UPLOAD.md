# V6.2.13 Staging Upload

Apply `Homeward_Website_V6_2_13_Targeted_Update.zip` to the current V6.2.12 staging branch, preserving the folder structure, then let Netlify run the existing `npm run build`.

## Test after deployment

1. Open the homepage on a phone or responsive browser at 360px, 390px, and 430px widths.
2. Confirm the compact header button reads **Let’s Talk**.
3. Confirm the desktop header still reads **Have a Conversation**.
4. Confirm the page no longer scrolls horizontally and the hero headline is not clipped.
5. Tap **Let’s Talk** and confirm the existing conversation calendar opens.
6. Open the hamburger menu and confirm its full-size button still reads **Have a Conversation**.
